## 한 문장 정의

**Workflow 는 사람이 절차를 정의하고, Agent 는 AI 가 상태를 보고 다음 Action 을 선택한다.**

```text
Workflow   문의 → 분류 → FAQ 검색 → 답변 → 종료
Agent      State → Reasoning/Policy → Action 선택 → Tool → Observation → 다음 Action
```

## 실제로는 가운데가 많다

기업에서 완전 자율 Agent 는 위험하다. 현실적인 형태는 **Bounded Agent** 다.
허용된 Action Space 를 먼저 정하고 그 안에서만 판단하게 한다.

```text
ANSWER · SEARCH · ASK_CLARIFICATION
ESCALATE · CREATE_TICKET · CHECK_ORDER
```

## 실패 지점

- Action Space 를 정의하지 않고 "알아서 판단하게" 두면 감사·재현이 불가능해진다
- Workflow 로 충분한 일에 Agent 를 써서 비용과 지연만 늘어난다
- 상태 전이를 그림으로만 그리고 코드로 강제하지 않는다

## 관점 전환

핵심은 질문을 바꾸는 것이다.

> "사용자에게 무엇을 말할 것인가" → **"이 상태에서 시스템이 무엇을 해야 하는가"**

이 전환이 Next-Action Routing 연구와 이어진다.
