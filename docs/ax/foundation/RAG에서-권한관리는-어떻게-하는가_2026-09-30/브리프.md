## 한 문장 정의

Enterprise RAG 의 핵심 문제. **보안은 LLM 에게 부탁하는 것이 아니라 검색 단계에서 막는 것**이다.

> Security should be enforced before generation.

## 구조

```text
사용자 → 인증 → Role 확인 → 접근 가능 문서 결정
→ 허용된 문서 안에서만 검색 → 답변
```

## 방법

**RBAC (Role-Based Access Control)**

```text
일반 직원 → 일반 사규
팀장      → 일반 사규 + 팀 문서
HR        → 인사 관련 문서
```

**문서 Metadata 필터링**

```text
department = HR
security_level = confidential
project = A
```

Retrieval 단계에서 이 값으로 걸러낸다.

## 실패 지점 — 가장 흔한 함정

Prompt 에 "사용자가 보면 안 되는 정보는 말하지 마" 라고 쓰는 것으로는 **충분하지 않다.**

- 검색은 이미 벡터 공간에서 끝났다
- 결과만 나중에 지우면 "몇 건이 나왔다"는 정보 자체를 못 막는다
- 원본을 새 시스템으로 복사해 오면 원본 시스템의 권한 변경이 인덱스에 반영되지 않는다

## 내 사례 (익명)

**건설사 A** — RBAC·감사로그를 요구사항으로 정의하고 구조에 반영했다.

> 표현 주의 — 실제 구현하지 않았다면 "설계했다 / 요구사항으로 정의했다 / 구조에 반영했다" 로 쓴다.
