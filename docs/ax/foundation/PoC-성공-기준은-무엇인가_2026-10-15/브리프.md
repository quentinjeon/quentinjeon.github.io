## 한 문장 정의

"정확도 90% 달성"만 성공 기준으로 잡으면 실패한다. **그 90% 가 업무적으로 의미 없을 수 있다.**

## 기준은 최소 네 개

| 축 | 묻는 것 |
|---|---|
| **Technical** | AI 가 문제를 해결 가능한가 |
| **User** | 실제 직원이 유용하다고 느끼는가 |
| **Business** | 시간·비용·매출 개선 가능성이 있는가 |
| **Scale** | 본사업으로 확장 가능한가 |

## 좋은 기준과 나쁜 기준

```text
나쁨   AI 가 중복 후보를 찾아내는가
좋음   관리자가 중복 여부를 판단할 때
       기존보다 빠르게 필요한 이력을 찾을 수 있는가
```

**AI 성능 → 사용자 행동 변화** 로 연결해야 한다.

## 실패 지점

- 성공 기준을 PoC 가 끝난 뒤에 정한다
- 평가셋이 없어 "좋아 보인다"로 판정한다
- 확장 가능성을 안 봐서 본사업에서 처음부터 다시 만든다

## 연결

로드맵 글의 **관문별 통과 기준**과 같은 이야기다.
