## 각도
'답변 잘하는 챗봇'과 '업무가 끝나는 챗봇'의 차이. 5단계 글로 연결.

## 연결할 기존 글
/ax/foundation/folder-agent-5-levels/

## 한 문장 정의

기업용 챗봇의 기준은 "답변 정확도"가 아니다. **대화 시스템이 아니라 업무 해결 시스템**으로 봐야 한다.

## 5가지 기준

| 기준 | 질문 |
|---|---|
| **정확성** | 답변이 맞는가 |
| **완결성** | 고객의 문제가 실제로 해결되는가 |
| **통제 가능성** | 틀릴 가능성이 높으면 답을 제한하거나 사람에게 넘길 수 있는가 |
| **운영 가능성** | 누가 무엇을 물었고 어떤 답변이 실패했는지 볼 수 있는가 |
| **비즈니스 효과** | 상담시간·전환율·업무시간 개선으로 이어지는가 |

## 예시로 설명하기

사용자가 "이 세탁기 설치 가능한가요?" 라고 물었을 때, 제품 특징만 잘 설명하면 좋은 챗봇이 아니다.

필요한 건 이것이다.

```text
설치 조건 확인 → 가능 여부 판정 → 추가 확인이 필요하면 상담 연결
```

## 실패 지점

**상담원 전환율이 높다고 무조건 나쁜 게 아니다.** AI 가 억지로 틀린 답을 내놓는 것보다, 구매 상담이나 복잡한 문의를 사람에게 정확히 넘기는 편이 나은 경우가 많다.

지표를 볼 때 이 해석을 함께 말할 수 있어야 단순 챗봇 기획자와 갈린다.

## 내 사례 (익명)

**가전 브랜드 인증점 상담 챗봇** — 실사용자 기반 운영 지표(응대 성공률·상담원 전환·fallback)를 보며 개선한 경험.

> 구체 운영 수치는 고객사 데이터이므로 이 문서에 쓰지 않는다. 면접에서 필요하면 별도 메모 참조.
