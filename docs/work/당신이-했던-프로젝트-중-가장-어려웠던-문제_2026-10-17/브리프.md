## 표적 검색어
(브랜딩 글 · 키워드 표적 아님)

## 각도
검색 유입보다 신뢰 형성용. 실패와 되돌린 경험을 솔직하게.

## 연결할 기존 글
/work/

## 한 문장 정의

정답이 없는 질문이다. **지원 직무에 따라 다른 프로젝트를 고른다.**

## 직무별 선택

| 지원 직무 | 고를 사례 | 강조할 것 |
|---|---|---|
| **AI Product Manager** | 가전 브랜드 인증점 챗봇 | 실사용자 · 운영 지표 · fallback · 상담원 전환 · 지속 개선 |
| **AX / AI Consultant** | 건설사 B 하자접수 | 현업 요구사항 · 대규모 데이터 · 요구사항을 데이터 문제로 전환 · 확장안 |
| **GEO 직무** | 가전 브랜드 GEO | 대규모 질문셋 · Multi-LLM · Category/Product/Channel · Content Loop |
| **Research 혼합** | Next-Action Routing 연구 | Real-world log · Action Taxonomy · Human Gold · Failure Analysis |

## 이 글의 성격

검색 유입보다 **신뢰 형성용**이다. 키워드를 노리지 않는다.

## 잘 쓰는 법

- **실패와 되돌린 경험**을 솔직하게 쓴다. 성공만 나열하면 신뢰가 떨어진다
- 내가 한 것과 팀이 한 것을 구분한다
- 수치를 쓸 때는 측정 기준을 함께 쓴다. 목표치를 실측치처럼 쓰지 않는다

## 표현 주의

구현하지 않은 부분은 **"설계했다 / 요구사항으로 정의했다 / 구조에 반영했다"** 로 쓴다.
과장은 꼬리질문 한 번에 무너진다.

## 꼬리질문 대비

```text
Q1 가장 어려웠던 문제는
Q2 그때 무엇을 바꿨나요
Q3 다시 한다면 어떻게 하시겠어요
Q4 본인이 한 부분은 어디까지인가요
```

## 체크리스트
- [ ] 한 문장 정의를 글 앞부분에 넣었는가 (AI 검색이 발췌할 수 있게)
- [ ] 표 또는 체크리스트가 하나 이상 있는가
- [ ] seo_title 이 사이트명 포함 60자 이내인가
- [ ] description 을 직접 썼는가 (기본 문구 복제 금지)
- [ ] 본문 맨 앞에 `# 제목` 을 쓰지 않았는가
- [ ] 기존 글로 내부 링크를 걸었는가
- [ ] 지어낸 수치나 고객사 성과가 없는가
